Privacy Policy

Last updated: November 17, 2026

BCR Analytics is a private tool used only by the owner of the Body Cam Report YouTube channel. This policy explains what it does with data it receives from Google.

What data it accesses

With the channel owner's permission, BCR Analytics uses these read-only Google scopes:

  • youtube.readonly - the channel's video list and public statistics
  • yt-analytics.readonly - the channel's YouTube Analytics reports (views, watch time, subscribers, traffic sources)
  • yt-analytics-monetary.readonly - the channel's estimated revenue reports

It cannot upload, edit, delete or post anything, and it does not access any other Google data.

How the data is used

The data is used only to produce performance reports for the channel owner. It is not sold, shared with third parties, or used for advertising.

Where it is stored

Data is stored on the channel owner's own computer. Sign-in tokens are stored there with owner-only file permissions. Nothing is stored on a public server.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. The locally stored data can be deleted by the channel owner at any time.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
